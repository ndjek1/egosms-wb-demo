What happens when you connect an account?

  1. For a new number, Meta asks the client to select or create their business portfolio, WABA and phone number.
  2. For an existing WhatsApp Business app number, choose Connect existing app number . The client confirms the number in Meta and keeps using the mobile app.
  3. egoSms securely exchanges the one-time authorization code on the server.
  4. The WABA is subscribed to this app's webhooks. New Cloud API numbers are registered; coexistence numbers are not re-registered.
  5. For coexistence, Meta synchronizes contacts and eligible message history only when the client approves those options.
  6. The resulting access token is encrypted and assigned only to the currently logged-in egoSms user.
